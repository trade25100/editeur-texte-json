# Éditeur de valeurs Texte JSON

Site statique compatible GitHub Pages, sans serveur.

## Déploiement
1. Créer un dépôt GitHub public.
2. Importer `index.html` à la racine du dépôt.
3. Aller dans Settings → Pages → Build and deployment → Deploy from a branch.
4. Sélectionner `main` et `/ (root)`, puis enregistrer.

Ouvrir le lien GitHub Pages généré. Le JSON est traité localement dans le navigateur.
